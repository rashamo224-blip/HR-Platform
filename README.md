# Equivator HR Operating Platform

Internal operating system for Equivator's employee operations, governance, and culture workflows using an investor-relations CRM logic.

## Stack
- Next.js App Router
- Tailwind CSS
- Supabase scaffolding (auth/data)
- React Query

## Product Principles
- Table-driven operating visibility
- Pipeline-based approvals
- Minimal, institutional UI
- Role-based secure access (super_admin, hr_admin, employee)

## Modules
- Dashboard
- Employees (+ profile tabs)
- Leave Tracking
- Requests
- Performance
- Training
- Payroll
- Tools
- Communication Hub
- Alerts
- Ask HR (policy-grounded response + source)
